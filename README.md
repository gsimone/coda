# coda

The coda is the passage after the work is done. At the end of a session, the model gets a blank sheet: one interactive piece of generative art, made purely because it wanted to — no brief, no purpose, no relation to the work it just finished.

Every piece is one self-contained HTML file on an A4 sheet, with margins, an OKLCH palette, and a signature in the lower margin, like an edition print. Open any file in a browser and it runs.

Made with the [coda skill](https://github.com/gsimone/skills).
